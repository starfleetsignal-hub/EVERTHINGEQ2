## Description

*"Mischievous voodoo doll escaped from the laboratory of Nektropos castle, Kenny now roams through the darkest parts of Nektulos forest..."*

## Notes

- Mercenary discovery:
  - non-Scout(scroll) Tracking **DOES** work, set track to [All].
  - Scout tracking **DOES** work, set to track [All].
  - Using **/target Kenny** does not work.
  - Asking a guard to "find" does not work.
  - Using Mercenary-track (ala [[Claz'zakla]]) **DOES** work.
