## Layout

This is a special instanced zone that is laid out like the [[Concordium Tower]] in [[South Qeynos]].

The bottom floor has the normal blue, yellow, and red teleporters but they are locked. Situated between each teleporter is a table with a glowing egg on it and room for one more egg.

- Table with the purple egg is between the blue and red teleporters.
- Table with the green egg is between the blue and yellow teleporters.
- Table with the orange egg is between the yellow and red teleporters.

You use the 3 eggs you loot from the keymaster to unlock each teleporter in turn.

***None of the mobs in this zone see invis or stealth, so either can be used to avoid unwanted combat.***
