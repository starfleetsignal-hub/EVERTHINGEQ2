## Notes

See the [[Guild Hall Amenities]] page for a list of all amenities.

- This amenity does not have a [[Guild Level]] minimum.
- This amenity is available for all types of [[Guild Hall|Guild Halls]].

## About this Amenity

Though the NPC looks like a guy steering a boat (with a wheel), this amenity functions like [[Travel in Norrath|world-travel globe]], offering guild members instant travel to all of the same locations seen when using the globe.

- This hireling's appearance **can not** be altered.
