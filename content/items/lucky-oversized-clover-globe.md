## Notes

- This item requires materials from [[Bountiful Brewday garden|Bountiful Brewday gardens]], which can only be seen during [[Brew Day]].
- If you have the materials, you can craft it all year though. If you run low on materials, check the [[Broker|broker]].
- If successfully crafted this recipe produces 2 of at once.
