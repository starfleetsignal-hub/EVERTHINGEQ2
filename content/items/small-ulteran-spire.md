## Notes

See the [[Guild Hall Amenities]] page for a list of all amenities.

- This amenity does not have a [[Guild Level]] minimum.
- This amenity is available for all types of [[Guild Hall|Guild Halls]].

## About this Amenity

This travel amenity offers guild members instant travel to all the same locations accessed using the [[Ulteran Spires]] and the Combine spires.

- It is a smaller version of the classic spire seen in zones like [[The Commonlands]] and [[Antonica]].
- The [[Wizard Portal Hireling]] serves the same function, but it is a NPC for guild halls.
