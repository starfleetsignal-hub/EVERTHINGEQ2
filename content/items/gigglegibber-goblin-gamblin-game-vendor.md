## About this Hireling

A Gigglegibber Goblin Gamblin' Game Vendor is a NPC.

- It functions just like a normal [[Gigglegibber Goblins' Lotto]] NPC.
- This NPC functions like a real world slot machine by selling tickets for a few silver per spin.
