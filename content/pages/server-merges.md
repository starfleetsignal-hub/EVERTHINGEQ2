Because server mergers can be confusing, this is a summary of the current servers listing all the servers that ultimately were merged into the present-day version.

## Notes on Names

- **Character Names:** In the event of duplicate character names during a merge, priority will be given to the character who has logged in to the game within the immediate sixty (60) days prior. If multiple characters have logged in within the past sixty (60) days, then the character which was created first will retain their name. Other same-named characters will have the letter "Z" (or several) added to their names automatically until their name is unique. Each player that is auto-renamed this way will get a free rename potion so that they may change their name.
- **Guild Names:** If two or more guilds have the same name at the time of the server merge, the oldest guild will keep the guild name, and other guilds with a conflicting name will have the letter "Z" (or several) added to their names automatically until their name is unique. If this happens to your guild, you will be offered a free guild name change. If you have a free guild name change, to select a new guild name the leader from a guild can use the command **/guild rename**. If there is no leader in your guild, **/initiate_guild_leader_vote** can be used by guild officers to help guilds choose a new leader.
