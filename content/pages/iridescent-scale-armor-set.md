**Iridescent Scale armor set**

- [[Iridescent Scale Helm]]
- [[Iridescent Scale Pauldrons]]
- [[Iridescent Scale Cuirass]]
- [[Iridescent Scale Vambraces]]
- [[Iridescent Scale Gauntlets]]
- [[Iridescent Scale Legplates]]
- [[Iridescent Scale Tonlets]]
- [[Iridescent Kite Shield]] *(See Note 1)*
- [[Iridescent Scourge of Silence]] *(See Note 2)*

No special bonus is gained by the wearing of multiple pieces of this set.

This complete set of **plate** FABLED armor (including shield and weapon) are dropped by: The [[Vision of Vox]] in [[Permafrost]]

The armor can only be worn by: [[Berserker]], [[Guardian]], [[Inquisitor]], [[Paladin]], [[Shadowknight]] and [[Templar]]s

**Note 1** - The shield can only be equipped by: *Berserker, Guardian, Paladin and Shadowknights*

**Note 2** - This weapon can only be equipped by: ,  and [[Beastlord]]s

**Note 3** - There is no set bonus for the armor, but all of the pieces have a "on hit" or "when hit" effect, making this armor set have a very potent effect in itself.
