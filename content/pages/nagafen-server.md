## Server Merger info

**Upcoming Server Mergers**

- No further mergers can occur due to this server merged with other servers to create the [[Skyfire (Server)|Skyfire]] server.  See 'Past Server Mergers' for more details on the final server merger for this merger.

**Past Server Mergers**

- September 22nd, 2009: [[Venekor (Server)|Venekor]],  merged into the [[Nagafen (Server)|Nagafen]] Server. Guilds were maintained with the older guild keeping its name and the younger guild receiving an 'X' at the end of its name. The same applied to characters.

- 11 November 2015: [[Nagafen (Server)|Nagafen]], [[Freeport (Server)|Freeport]], and [[Permafrost (Server)|Permafrost]] servers merged creating [[Skyfire (Server)|Skyfire]]. The merging servers were taken down for the merger on 11 November 2015 at 7am PST and the new [[Skyfire (Server)|Skyfire]] server came on-line at 12 November 2015 at 0740am PST.  When duplicate Guilds and Characters names occurred names were maintained as with past server mergers where the older Guilds and Characters kept their names and the younger Guilds and Characters had an 'z' added to the end of their names.
