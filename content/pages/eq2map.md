The EverQuest II Modular Atlas Project, or EQ2MAP, is a database of user-created maps and user-submitted Points of Interest, or POIs, with an in-game User Interface mod that adds dots to the map that display information about those POIs. A launcher keeps the MAP up-to-date in the same way that the EverQuest II Launchpad does.

If you don't have this mod, go get it! It is easy to install and well worth the effort!

After you install it, think about helping fill in Pages that need EQ2MAP info
