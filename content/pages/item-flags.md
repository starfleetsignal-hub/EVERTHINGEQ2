Item Flags are special properties assigned to most items in the game. These flags determine how an item can be used, traded, equipped, stored, or destroyed. Understanding these flags helps players manage their inventory and equipment more effectively.

## Item Flag Reference

| Flag | Description |
|---|---|
| **APPEARANCE-ONLY** | *This item can only be used in your appearance inventory.* |
| **ARTIFACT** | *Artifacts can only be obtained once per server.* |
| **ATTUNED** | *This item is attuned to you; you can't trade it or place it in the shared bank.* |
| **ATTUNEABLE** | *You need to attune it before you can use or equip it.* |
| **BUILDING-BLOCK** | *Counts as a building block in housing and has its own item limit. See [[Housing Item Limit and Building Blocks#Building Blocks\|here]].* |
| **HEIRLOOM** | *Can't be traded to other players, but can be transferred to alts via shared bank.* |
| **INDESTRUCTIBLE** | *Can't be destroyed, reforged, or sold; doesn't take damage on death.* |
| **INFUSABLE*** | *Can be [[Equipment Infusing\|infused]].* |
| **LORE** | *Only one copy allowed in bags or equipped.* |
| **LORE-EQUIP** | *Only one copy can be equipped, but extras can be stored in bags.* |
| **NO-EXCHANGE** | *Can't be used in item exchanges.* |
| **NO-DESTROY** | *Can't be destroyed or sold to NPCs.* |
| **NO-SALVAGE** | *Can't be salvaged.* |
| **NO-TRADE** | *Can't be traded or placed in shared bank.* |
| **NO-TRANSMUTE** | *Can't be transmuted.* |
| **NO-VALUE** | *Can't be sold, salvaged, or transmuted.* |
| **NO-ZONE** | *Disappears when leaving the zone; may reappear upon re-entry or be retrievable from a zone mechanic.* |
| **ORNATE** | *Can't be transmuted or salvaged.* |
| **REQUIRES-EQUIP** | *Must be equipped to gain benefits.* |
| **TEMPORARY** | *Disappears after a set time. For example, resurrection items vanish after one hour.* |

<sup>* Feature relating to item flag has been removed from the game.</sup>
