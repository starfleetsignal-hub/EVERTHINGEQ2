This is the TSO Armor Set (Tier 2) for: [[Crusader|Crusaders]] ( ) that can be obtained via the [[Void Shard Mission System]].

1. These pieces are available as vendor purchase from [[A mysterious Quellthulian]], designated as the <Greater Shard Armor Merchant> in [[Moors of Ykesha]] at the [[Dropship Landing Zone]] {{waypoint 1680, 452, 894}}.
   - They can also be created by crafters, and cost 2 - 3 shards less if crafted.
1. The cost of each piece is a certain number of shards, and the equivalent T1 piece.

These pieces are upgrades from the equivalent Tier 1 pieces from the set: [[Zealot's Zeal (Armor Set)]]  You no longer have to have the Tier 1 set to get these. You can buy T2 directly.

This armor set can be further upgraded to Fabled shard armor set (Tier 3): [[Knight of the Elements (Armor Set)]]

Note that the Void Shard costs in the above table are for vendor purchase. If purchased from a crafter, the Breastplate and the Epaulets cost three shards less, the other four pieces each cost two shards less.
