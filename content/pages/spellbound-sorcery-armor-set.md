<br>
This is the TSO Armor Set (Tier 2) for: [[Enchanter|Enchanters]] ( ) that can be obtained via the [[Void Shard Mission System]].

These pieces are available for vendor purchase from [[A mysterious Quellthulian]], designated as the <Greater Shard Armor Merchant> in [[Moors of Ykesha]] at the [[Dropship Landing Zone]] {{waypoint 1680, 452, 894}}. They can also be created by crafters.

These pieces are upgrades from the equivalent Tier 1 pieces from the set: [[Enthralling Magics (Armor Set)]]

This armor set can be further upgraded to Fabled shard armor set (Tier 3): [[Mindmelt (Armor Set)]]

Note that the Void Shard costs in the above table are for vendor purchase. If purchased from a crafter, the Robe and the Mantle cost three shards less, the other four pieces each cost two shards less.
