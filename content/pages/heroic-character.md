I can't seem to leave a message or make a discussion page for the producer note so I'll put this here.

If you can't upgrade or create a heroic character what you need to do is log all the way into the game.

Type /loadui Default then log out.

Then log back into the character select and you will see the upgrade or create free heroic options.

Then you can reload whatever UI mod's you are using. Jado818 (talk) 19:57, October 1, 2013 (UTC)
