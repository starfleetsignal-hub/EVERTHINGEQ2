Many city zones have a place for artisans to congregate and practice their crafts. These instances have special vendors and a broker, along with crafting stations. The villages in Qeynos and Freeport used to have tradeskill instances as well, but these were removed when Qeynos and Freeport were reworked.

See also: Tradeskill Zones

## Starting isles

### [[Queen's Colony]] and [[Outpost of the Overlord]]

- [[Tradeskiller's Workshop]] {{waypoint -19.66, -3.13, 154.24}}
  - Work Order Clipboard
  - Fuel Merchant/Recipe Merchant (Wholesaler) - Artisan 1-9 only
  - Crafting stations for all tradeskills
  - **Does NOT** have Rush Order foreman
  - **Does NOT** have Work Order foreman
  - **Does NOT** have Banker
  - **Does NOT** have Broker
  - **Does NOT** have Adorning and Tinkering Tasks NPC
  - **Does NOT** have Trades Coordinator (grandmaster)
  - **Does NOT** have Tradeskill Tutorial NPC
  - **Does NOT** have Crafting Trainer
  - **Does NOT** have Tradeskill Career Counsellor

## [[Qeynos]]

### North Qeynos in [[Qeynos Capitol District]]

- The [[Ironforge Exchange (POI)]] in North Qeynos in [[Qeynos Capitol District]] {{waypoint 333, -21, -108}}, the non-instanced crafting building. Contains:
  - Rush Order foreman
  - Work Order foreman
  - Work Order Clipboard
  - Fuel Merchant
  - Adorning and Tinkering Tasks NPC
  - Trades Coordinator (grandmaster)
  - Tradeskill Tutorial NPC
  - Crafting Trainer
  - Tradeskill Career Counsellor
  - Crafting stations for all tradeskills
  - Faction merchant (Ironforge Exchange)
  - **Does NOT** have a broker (nearest is inside the tradeskill instance at {{waypoint 330, -20, -99}})
  - **Does NOT** have a bank (nearest is across the street at Qeynos Hold {{waypoint 274, -18, -120}})
- [[The Ironforge Exchange]] (tradeskill instance) in North Qeynos in [[Qeynos Capitol District]] {{waypoint 331, -20, -99}}. Contains:
  - Rush Order foreman
  - Work Order foreman
  - Work Order Clipboard
  - Fuel Merchant
  - Broker
  - Crafting stations for all tradeskills
  - **Does NOT** have a bank
  - **Does NOT** have an Adorning and Tinkering Tasks NPC
  - **Does NOT** have a Trades Coordinator (grandmaster)
  - **Does NOT** have a Tradeskill Tutorial NPC
  - **Does NOT** have a Crafting Trainer
  - **Does NOT** have a Tradeskill Career Counsellor
  - **Does NOT** have a Faction merchant
  - All amenities that this location does not have can be found nearby outside at the crafting building or Qeynos Hold across the street.

## [[Maj'Dul]]

On the western edge of the City, in a building known as [[The Golden Scepter|the Golden Scepter]], there is a complete set of public crafting stations and specialized fuel and book merchants.

## [[Haven]]

[[Ekroosik's Replicators]], a crafting area (not an instance). Reach by entering a tunnel at {{waypoint -46, -68, -87}} and proceeding until the tunnel finally ends in a large cave {{waypoint 26, -33, -150}}. Contains:

- Rush Order foreman
- Work Order foreman
- Work Order Clipboard
- Fuel Merchant
- Crafting Trainer
- Tradeskill Career Counsellor
- Crafting stations for all tradeskills
- **Does NOT** have an Adorning and Tinkering Tasks NPC
- **Does NOT** have a Trades Coordinator (grandmaster)
- **Does NOT** have a Tradeskill Tutor
- **Does NOT** have a faction merchant
- **Does NOT** have a Banker or Broker, but these two amenities are available nearby in Haven

## [[Kelethin]]

In Kelethin the crafting area is not an instance. There are several places in the city where different types of crafters get together.

- [[Gearheart's Forge]] - *has vendors and crafting stations for [[Armorsmith|Armorsmiths]], and [[Weaponsmith|Weaponsmiths]]*
- [[Kelethin Research Library]] - *has vendors and crafting stations for [[Alchemist|Alchemists]], [[Sage|Sages]], and [[Provisioner|Provisioners]]*
- [[Joleena's Restaurant]] - *has vendors and crafting stations for [[Provisioner|Provisioners]]*
- Building north of [[Kelethin First Regional Bank]] - *has vendors and crafting stations for [[Jeweler|Jewelers]], [[Alchemist|Alchemists]], and [[Sage|Sages]]*
- [[Tunare's Pages]] in [[Kelethin]] {{waypoint 459, 93, 339}}. Contains:
  - Rush Order foreman
  - Work Order foreman
  - Work Order Clipboard
  - Fuel Merchant
  - Broker
  - Adorning and Tinkering Tasks NPC
  - Trades Coordinator (grandmaster)
  - Tradeskill Tutor
  - Crafting Trainer
  - Tradeskill Career Counsellor
  - Crafting stations for all tradeskills
  - Faction merchant (Tunare's Pages)
  - **Does NOT** have a Banker
  - A banker is located nearby in [[Kelethin]] at {{waypoint 268.5, 106.6, 172.73}}
