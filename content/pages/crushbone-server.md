**Crushbone** is an EverQuest II PVE server. It ranks as one of the highest population PVE servers.

On February 8, 2006, the Innothule server was merged into Crushbone.<br>
More recently, on February 16th, 2011, Lucan D'Lere server was merged into Crushbone.
