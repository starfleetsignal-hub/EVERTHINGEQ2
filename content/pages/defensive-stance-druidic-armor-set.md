## Notes

There are actually several [[Defensive Stance (Armor Set)|Defensive Stance]] sets with the same name and effects. Items from a different set will not contribute towards the set bonus in another set. In other words, you will not get a two set bonus for just wearing both a Druidic Bracelet and a Stone Tower Earring, since they belong in different sets.
