This zone contains several groups of named mobs. Each named in a group can be spawned in different ways, and once a named from a group has been spawned, the other named from that group will be unavailable until the instance is reset or expires. See Bosses below for information on how to spawn named in each group.

Named from the first 4 named groups (A, B, C, and D) can be spawned in any order. Once a named from all 4 groups has been killed, Group E will become attackable. When Group E is killed, Group F (High Shaman) will become attackable. The final group (Group G) will only spawn after the zone boss (High Shaman Rakada Darkpaw) has been killed.
